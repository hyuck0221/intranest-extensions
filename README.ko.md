# IntraNest 확장 프로그램

Chrome 도구 모음에서 팀의 IntraNest 링크를 바로 엽니다. 확장 프로그램은 인트라넷의 서버 PC에 직접 연결합니다.

**현재 버전:** `0.1.0`  
**언어:** [English](README.md)

## 시작하기

1. IntraNest 서버 호스트에게 서버 주소와 팀 접근 키를 받습니다.
2. [GitHub Releases](https://github.com/hyuck0221/intranest-extensions/releases)에서 최신 ZIP을 내려받아 압축을 풉니다.
3. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켠 다음 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다. 압축을 푼 IntraNest 폴더를 선택하세요.
4. Chrome 도구 모음에서 IntraNest를 열고 서버 주소와 접근 키를 입력한 다음 연결합니다.
5. Chrome에서 입력한 서버 주소의 접근 권한을 요청하면 허용합니다. 확장 프로그램은 해당 서버 origin만 요청합니다.

## 공유 링크 사용하기

팝업을 열면 팀의 공유 링크가 표시됩니다. 링크를 누르면 새 탭으로 열리고 **링크 추가**를 선택하면 새 링크를 공유할 수 있습니다. 링크와 제목은 IntraNest 서버에 저장되어 팀에서 함께 관리합니다.

서버 연결 정보는 다시 연결할 수 있도록 이 Chrome 프로필에 저장합니다. 확장 프로그램은 다른 웹 페이지를 읽거나 수정하지 않습니다. 채팅과 파일 공유는 IntraNest 관리자 페이지에서 사용할 수 있습니다.

## 확장 프로그램 업데이트

확장 프로그램의 **설정**에서 **업데이트 확인**을 선택합니다. Chrome은 공개 GitHub 릴리스 확인 권한을 별도로 요청합니다. 새 버전이 있으면 팝업에 **업데이트 다운로드**와 **다음에 하기**가 표시됩니다. ZIP을 내려받아 압축을 풀고 `chrome://extensions`에서 기존 폴더를 새 폴더로 바꾸세요.

개발자 모드로 불러온 확장 프로그램은 ZIP 업데이트를 자동 설치하지 않습니다. 처음 불러온 폴더 경로를 유지한 채 새 ZIP의 파일을 그 폴더에 덮어쓰고 `chrome://extensions`에서 **새로고침**을 누르세요. 같은 확장 프로그램 폴더의 연결 정보는 유지됩니다.

## 사용자 정보

서버 주소와 팀 키는 이 Chrome 프로필에 저장합니다. 공유 링크는 설정한 서버로 전송됩니다. 릴리스 확인은 GitHub에 연결하지만 팀 콘텐츠는 포함하지 않습니다. 자세한 내용은 [개인정보 처리방침](https://github.com/hyuck0221/intranest-web/blob/master/public/privacy.html)을 확인하세요.

## 버전 배포

루트의 `version` 파일이 이 프로젝트 버전을 관리하며 `manifest.json`과 값이 같아야 합니다. `master`에 push할 때 현재 버전이 최신 릴리스보다 높으면 GitHub Release와 ZIP을 만듭니다. 서버, 웹, 확장 프로그램 버전은 각각 따로 관리합니다.
